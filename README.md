# 🚗 스마트 주차장 차량 크기 분류 시스템 (Smart Parking Vehicle Classifier)
### ⚡ Google Gemini 2.5 Flash Vision AI 기반 초정밀 차종 식별 및 규격 분류

주차장 차량 사진을 업로드하면 차량을 **경차(Compact) / 중형(Mid-size) / 대형(Large/SUV)**으로 정밀 분류하고, 적합한 주차구획과 주차 혜택을 안내하는 프런트엔드 웹 시스템입니다.

---

## 🌟 주요 기능 및 업그레이드

1. **Google Gemini Vision AI 연동 (정확도 99%)**
   - 상단 **[⚡ Gemini AI 설정]**에서 무료 API 키를 등록하면 즉시 활성화
   - 차량의 **실제 제조사 및 차종 모델명**(예: 현대 아반떼 CN7, 기아 레이, 현대 팰리세이드 등)을 시각적으로 정확히 식별
   - 차종의 공식 제원(전장 × 전폭 × 전고)을 기반으로 대한민국 자동차관리법 및 주차장법에 따라 분류
   - API 키가 없어도 내장 **스마트 시뮬레이션 모드**로 항상 안전하게 동작

2. **간편한 이미지 업로드 & 미리보기**
   - 파일 선택(클릭), **드래그 앤 드롭(Drag & Drop)** 지원
   - **클립보드 단축키(Ctrl+V)** 붙여넣기 지원 (캡처 도구/웹 이미지 복사 후 바로 붙여넣기)
   - 차량 사진이 없을 때 바로 테스트 가능한 **원클릭 샘플 차량 3종** (경차, 중형, 대형)

3. **AI 종합 판정 결과 카드**
   - **식별된 차종 모델명 배너**: AI가 읽어낸 실제 차량 명칭 표시
   - **판정 등급 배지**: 경차(에메랄드) / 중형(블루) / 대형(골드)
   - **신뢰도(Confidence %)** 및 게이지 바
   - **AI 분석 소견**: 차종 특징과 법적 규격에 따른 판정 이유 상세 설명
   - **3대 등급별 확률 분포** 비교 바 차트
   - **추천 주차 구획 & 팁**: 경차 전용(2.0m×3.6m), 일반형(2.5m×5.0m), 확장형(2.6m×5.2m)

4. **이번 세션 분석 이력 (History)**
   - 세션 동안 분석한 차량 썸네일, 식별 모델명, 판정 등급, 신뢰도, 시간 저장 (`sessionStorage`)
   - 이력 클릭 시 메인 화면에 당시 분석 결과 즉시 재표시
   - 개별 삭제 및 전체 삭제 지원

5. **법적 규격 가이드 섹션**
   - 대한민국 자동차관리법 및 주차장법 시행규칙에 근거한 규격 기준표

## 🚀 로컬 실행 방법

**별도의 설치나 빌드 과정 없이 바로 실행할 수 있습니다.**

### 방법 1: `start-server.bat` 더블클릭 (가장 추천)
- 탐색기에서 `start-server.bat`을 더블클릭하면 로컬 서버가 켜지면서 브라우저가 자동 실행됩니다.

### 방법 2: `index.html` 파일 더블클릭
- 탐색기에서 `index.html`을 그냥 더블클릭해서 열어도 보안 오류 없이 100% 정상 작동합니다.

## 🔑 Google Gemini API 무료 키 발급 및 사용법

1. [Google AI Studio (https://aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey)에 구글 계정으로 로그인합니다.
2. **"Create API key"**를 눌러 무료 API 키를 발급받습니다.
3. 우리 웹사이트 상단 우측의 **[⚡ Gemini AI 설정]** 버튼을 클릭합니다.
4. 발급받은 키(`AIzaSy...`)를 붙여넣고 **[저장 및 AI 모드 켜기]**를 누르면 끝!
5. 상단 뱃지가 `🟢 Gemini Vision 2.5 활성화됨`으로 바뀌며 초정밀 AI 비전 분석이 시작됩니다.
*(입력한 키는 외부 서버로 전송되지 않고 본인의 브라우저 localStorage에만 안전하게 보관됩니다.)*

## ☁️ Vercel 배포 방법

정적(Static) 웹사이트로 구성되어 있어 Vercel에 단 1분 만에 배포할 수 있습니다.
- GitHub에 프로젝트를 푸시한 후 [Vercel](https://vercel.com)에서 저장소를 Import하여 배포하면 완료됩니다.
